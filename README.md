Nowoczesne, lekkie **CV / Portfolio** w React + Vite.  
Automatycznie **budowane i publikowane** z GitHub Actions na GitHub Pages.  

👉 **Live**: [krzysztof-broniszewski.github.io/krzysztof-cv](https://krzysztof-broniszewski.github.io/krzysztof-cv/)

> _Projekt zrealizowany jako połączenie estetycznego frontendu i profesjonalnego workflow DevOps – gotowy do dalszej rozbudowy._

---

## ✨ Funkcje
- Nowoczesny interfejs (React + Tailwind)
- Dark-friendly design
- Sekcje: O mnie, Umiejętności, Projekty, Doświadczenie, Kontakt
- Pełna responsywność (mobile-first)
- Automatyczny **deploy z GitHub Actions**
- Gotowy pod **SEO + OpenGraph**
- Możliwość integracji z API / backendem w przyszłości

## 🧰 Stos technologiczny

### 🔹 Frontend
| Technologia | Zastosowanie |
|--------------|--------------|
| **React 18** | komponenty, JSX, React Hooks |
| **Vite 5** | szybki bundler + dev serwer |
| **Tailwind CSS 3** | responsywny i lekki styl (dark mode) |
| **PostCSS / Autoprefixer** | optymalizacja CSS |
| **TypeScript (opcjonalnie)** | statyczne typowanie komponentów |
| **Lucide Icons / Heroicons** | minimalistyczne ikony SVG |
| **Framer Motion** | animacje i mikrointerakcje |
| **React Router 6** *(jeśli użyty)* | nawigacja z `basename="/krzysztof-cv"` |
| **React Helmet** *(opcjonalnie)* | meta tagi i SEO |

### 🔹 Build & Deploy
| Technologia | Zastosowanie |
|--------------|--------------|
| **Node.js 20** | środowisko uruchomieniowe |
| **npm** | zarządzanie pakietami |
| **GitHub Actions** | CI/CD – automatyczny build i deploy |
| **GitHub Pages** | hosting statyczny |
| **Vite Preview** | test buildu lokalnie (`npm run preview`) |

### 🔹 Dev Tools
| Narzędzie | Zastosowanie |
|------------|---------------|
| **VS Code** | główne IDE |
| **ESLint + Prettier** | linting i formatowanie kodu |
| **Git / GitHub CLI** | kontrola wersji i zarządzanie repo |
| **PowerShell / Bash** | środowisko uruchamiania komend |
| **GitHub Copilot / Copilot Chat** | autouzupełnianie i optymalizacja kodu |
| **npm-run-all / concurrently** *(opcjonalnie)* | równoległe procesy dev |
